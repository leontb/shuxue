# 教学设计规则

## 从题目关系选图

| 关系 | 优先图示 | 必须看得见 | 常见失误 |
|---|---|---|---|
| 一个量的是几分之几、比它多/少 | 等份条形图 | 单位“1”、每份值、增加或减少部分 | 只画格子，不解释为什么这样分 |
| 同路程比较时间与速度 | 时间条→同时间路程条 | 时间比和速度比为何相反 | 直接宣布速度比，学生不知道换了什么量 |
| 相遇、追及 | 共用比例的路线与运动点 | 起点、方向、速度、相遇或追及前后 | 漂亮的车辆动画与算式无关 |
| 正负方向与路程 | 位置数轴＋累计里程条 | 向左位置减小、里程仍增加 | 把位移和总路程合成一个读数 |
| 端点折返 | 数轴＋事件时间线 | 哪个端点触边、延迟出发、区间切换 | 用整段区域长度代替线段移动距离 |
| 成本、售价、销量、利润 | 同一商品的量关系图 | 售价−进价，再乘本商品销量 | 把不同商品的数字随意相减 |
| 等量和、消元 | 重叠图形、同色配对与抵消 | 相等的两边共有哪部分 | 只给代数步骤，画面没有对应变化 |
| 分类与全部解 | 分段表、事件轴、局部放大 | 每段的条件、候选解与排除理由 | 找到两个解就停止，不检查后续 |

## 先画关系，再写算式

每一个视觉动作必须对应一个数学动作。例如：

- 把五格中的一格涂色，表达选取五分之一。
- 在四格旁补一格，表达在原来四份基础上增加四分之一。
- 两端向中间移动，表达两边都在缩短同一间隔。
- 两个点越过彼此后交换左右，表达“相距1”可能出现第二次。
- 西行路段仍接到累计条后面，表达实际路程增加。

给条形图定义每格的含义。至少说明“谁被分成几份”“每份对应多少”。有两个比较基准时，分成两个有名称的条形图，不靠相同颜色暗示同一单位。

若不是按比例画，明确标注“示意”；不要把不按比例的图用于读取数值。

## 每一步的文字限度

- 标题直接说本步要解决的问题。
- 图前1～2句交代观察任务。
- 图旁用短标签解释对象，不写一整段理论。
- 主区只保留当前必需算式；形式化推导可放展开解析。
- 正确反馈用一句确认；详细理由在图上或解析中保留，不能600毫秒后消失。

这些是设计起点，不是字数硬门槛。必要定义不能为了短而省掉。

## 选择题要有教学用途

选择应迫使学生做一个判断，例如“这次把谁看成单位1”“耗油看哪条距离”“两点现在每秒靠近多少”。不在每步都问已经原样显示的大数字。

每个错项对应一种真实误解，并给出能帮助改想法的提示：

| 误解 | 提示方式 |
|---|---|
| 比较标准错了 | 指向题干中的“比谁”“是谁的” |
| 忘了延迟出发 | 并列显示总计时和实际运动时长 |
| 把路程当位置 | 对比向左时两个读数的不同变化 |
| 只算相遇前 | 播放越过彼此的局部关键帧 |
| 单位错了 | 将“元/件×件”“单位/秒×秒”对应到所求量 |
| 漏解或多解 | 检查候选时刻属于哪段、端点是否重复计算 |

问“所有时刻”时，正确项必须列出完整集合；不能把一项部分正确、一项全部正确，却不说明要选全部答案。

## 概括成一图

建议3～5个关系节点，每个节点都带本题中的量或例子：

输入量 → 关键关系 → 运算结果 → 范围/单位检验。

运动题可以用事件时间线与相遇前后两帧；分数题可以用两条明确标注基准的等份条；利润题可以用两条同款商品的计算链再汇合。

删除“培养逻辑思维、提升抽象能力”等无法在图上定位的泛化口号。也不要把原本五段长文分别塞进五张卡片。

## 两道变化训练

- 第一题让学生复用刚学会的关系。
- 第二题至少改变一个需要重新判断的条件或问法。
- 改数值仍可能是有效训练，但不能两题都机械替换数字。
- 两题条件要独立明确；若依赖原题数据，列出需要沿用的条件。
- 错题允许重选；不用填空，不把选错惩罚为重看所有步骤。
- 答对后自动继续；仍能回看刚才的解析。

## 教学判断的边界

数学核验、页面功能通过和学生理解是三件事。只凭成人或Agent看懂，不能宣称“六年级一定能看懂”或“学习效果已验证”。

有真实学生试用时，优先观察能否解释每个图形代表什么、指出为什么这样列式、独立完成第二道变式。没有试用时，将这些写成待验证项。
