# 一桶水原来有多少升？——六年级教学方案

> 本次交付：数学核验、4步教学分镜、每步单选题与针对性反馈、两道变式训练。面向已学分数意义、分数乘除法的六年级学生。

## 一、数学核验

### 1. 原题与条件

**原题：** 一桶水，第一次用去总量的1/4，第二次用去剩下水量的1/3，最后剩30升。原来有多少升水？

| 核验项 | 确认结果 |
|---|---|
| 已知量 | 第一次用去原来总量的1/4；第二次用去第一次剩下水量的1/3；最后剩30升 |
| 所求量、单位 | 原来总量，单位为升 |
| 第一次的单位“1” | 用水前原来的一整桶水 |
| 第二次的单位“1” | 第一次用水后剩下的水；它是原来总量的3/4 |
| 条件解释 | “剩下水量”指第一次用水后、第二次用水前的水量；依题意只计这两次用水 |
| 变量范围 | 原来水量大于0；每次用去的比例都在0与1之间 |
| 启动、折返、方向条件 | 本题无运动情境，不适用 |
| 附带答案或批注 | 未提供；先按题意独立求解 |

### 2. 独立求解

把原来总量平均分成4份。第一次用去1份，剩3份。第二次把这**剩下的3份**看成一个新的整体，平均分成3份，取走其中1份；这1份恰好是原来总量的1/4。因此最后剩原来的2份，2份对应30升。

- 原来的一份：30÷2＝15（升）。
- 原来的四份：15×4＝60（升）。

**答：原来有60升水。**

教师核验模型：设原来有 (x) 升，则

\[
x\left(1-\frac14\right)\left(1-\frac13\right)=30,
\qquad \frac34\times\frac23=\frac12,
\qquad x=30\div\frac12=60.
\]

这里的两个剩余比例分别针对两个不同整体，因而相乘。不能写成 $1-\frac14-\frac13$：第二次的1/3并不是原来总量的1/3。

也可从结果倒推：第二次后剩30升，是第二次前的2/3，所以第二次前有 $30\div\frac23=45$ 升；45升是原来总量的3/4，所以原来有 $45\div\frac34=60$ 升。两次除法分别还原不同阶段的完整水量。

### 3. 关键状态与边界

| 状态 | 用去的水 | 剩下的水 | 对应原来4份图 |
|---|---:|---:|---|
| 初始 | 0升 | (x=60) 升 | 完整4份 |
| 第一次后 | 第一次用去 (x/4=15) 升 | (3x/4=45) 升 | 剩3份 |
| 第二次后 | 第二次用去 ((3x/4)÷3=x/4=15) 升 | (x/2=30) 升 | 剩2份 |

**回代检查：** 60÷4＝15；60－15＝45；45÷3＝15；45－15＝30。两次用去的水加最后剩水为15＋15＋30＝60升。

**解与边界：** 最后水量是原来总量的1/2，比例为正且固定，30升只能对应原来60升，故有且仅有一个正解。各阶段水量满足60＞45＞30＞0，第二次用去15升不超过当时剩下的45升。0升或负数均不可能得到题给的30升。

**含义检查：** 两次都用15升是本题分数关系产生的结果；不能由此说两次的单位“1”相同。两次分别计算60的1/4和45的1/3。

## 三、4步教学分镜

### 第1步：第一次用水后，还剩原来的几份？

| 分镜字段 | 内容 |
|---|---|
| 本步判断 | 第一次用去原来4等份中的1份，所以剩下3/4 |
| 核心画面 | A条4个等宽格；全条括号写“原来总量：单位1”；每格写“原量的1/4” |
| 变化 | 第1格标“第一次用去”并淡化，其余3格保持水的颜色；显示剩余部分的整体括号 |
| 一句解释 | 原来平均分成4份，用去1份，就还剩3份 |
| 作答后保留的关系 | $1-\frac14=\frac34$，第一次后剩3格 |

**单选题：** 第一次用水后，剩下的水占原来总量的几分之几？

| 选项 | 判断及针对性反馈 |
|---|---|
| A. 1/4 | 错。1/4是刚刚用去的那1格；看看没有被淡化的部分还有几格 |
| **B. 3/4** | **对。原来4等份中还剩3份** |
| C. 3/3 | 错。题目这里问“占原来总量”，分母对应原来的4格，不能换成剩下的3格 |

**持续可见的完整解释：** “总量”指原来整桶水，所以把原来总量作为单位“1”。用去1/4，就是从原来的4等份中拿走1份，剩下3份；这3份占原来总量的3/4。此时还不知道一格是多少升。

### 第2步：第二次的1/3，要从哪一个整体里取？

| 分镜字段 | 内容 |
|---|---|
| 本步判断 | 第二次应从第一次后剩下的3等份中取1份 |
| 核心画面 | A条继续保留；将其中未用的3格对应呈现在下方B条，B条标题写“第一次后剩量：新的单位1” |
| 变化 | B条整条括号高亮，再均分成3份；每份恰好对应A条的一格；将B条的第一格标为“第二次用去” |
| 一句解释 | 剩下的3格是这一次的整体，取它的1/3，就是取走其中1格 |
| 作答后保留的关系 | $\frac34\times\frac13=\frac14$：第二次用去原量的1/4 |

**单选题：** 第二次用去的水，应该怎样在图中表示？

| 选项 | 判断及针对性反馈 |
|---|---|
| A. 把原来完整的A条三等分，取其中一份 | 错。题干写的是“剩下水量的1/3”；先指向第一次后剩下的3格，再三等分 |
| B. 把A条的一格再三等分，只取一个小份 | 错。这是在求“原来总量的1/4的1/3”；第二次的整体是剩下3格，不是其中一格 |
| **C. 把剩下的B条三等分，取其中一格** | **对。第二次以第一次后剩量为整体，取3份中的1份** |

**持续可见的完整解释：** 第二次的单位“1”已经换了：它是第一次后剩下的水，也就是原来4格中的3格。把这3格平均分成3份，每份正好一格，所以第二次用去原来总量的1/4。上条一格称为“原量的1/4”，下条同样多的水称为“剩量的1/3”；分数不同，是因为比较的整体不同。

### 第3步：最后的30升，对应原来的几份？

| 分镜字段 | 内容 |
|---|---|
| 本步判断 | 最后的30升对应原来4等份中的2份 |
| 核心画面 | A条第1格标第一次用去，第2格标第二次用去，第3、4格为仍在桶里的水；B条保留第二次前后对应关系 |
| 变化 | 将两次用去的格子分别标记；只对最后留下的两格加共同括号，标“30升” |
| 一句解释 | 原来4份，第一次拿走1份，第二次再拿走1份，最后2份就是30升 |
| 作答后保留的关系 | 30升＝原来2份；$\frac34\times\frac23=\frac24=\frac12$ |

**单选题：** 图中哪几份水合起来是题目的30升？

| 选项 | 判断及针对性反馈 |
|---|---|
| **A. 最后留下的2份** | **对。30升对应两次用水后仍留下的2格** |
| B. 第一次后剩下的3份 | 错。3份是第二次用水前的水；题目的30升还要扣除第二次用去的那1份 |
| C. 第二次用去的1份 | 错。题干说“最后剩30升”，应指仍在桶里的部分，不是被用去的部分 |

**持续可见的完整解释：** 第一次后剩3份，第二次从这3份中取走1份，留下2份。题目给出的30升出现在第二次用水之后，所以要标在最后留下的两格下，而不能标在第一次后剩下的三格下。这2份占原来4份的2/4，也就是1/2。

### 第4步：已知2份是30升，怎样求原来的4份？

| 分镜字段 | 内容 |
|---|---|
| 本步判断 | 先由2份求1份，再求原来的4份 |
| 核心画面 | 两格共30升的括号持续保留；把30升均分给两格，每格显示15升；同尺度的原来4格随之显示各15升 |
| 变化 | 先高亮一格，显示30÷2＝15；再高亮原来全条，显示15×4＝60 |
| 一句解释 | 两份是30升，一份就是15升，原来四份就是60升 |
| 作答后保留的关系 | $30\div2\times4=60$（升），并保留回代核验 |

**单选题：** 已知原来的2份是30升，求原来的4份，哪个算式正确？

| 选项 | 判断及针对性反馈 |
|---|---|
| A. 30÷3×4＝40（升） | 错。30升对应最后2份，不是第一次后剩下的3份；先核对30升括号圈住几格 |
| B. 30×2/4＝15（升） | 错。30升已经是原来水量的2/4；要求更大的原来总量，应除以2/4，而不是再取它的2/4 |
| C. 30÷(1－1/4－1/3)＝72（升） | 错。这样把第二次的1/3也当作原来总量的1/3了；原题第二次取的是B条的1/3 |
| **D. 30÷2×4＝60（升）** | **对。先求原来每份15升，再求4份60升** |

**持续可见的完整解释：** 图中每格同样多，最后的2格合起来是30升，所以一格为30÷2＝15升。原来有4格，因此原来为15×4＝60升。把60升代回原题：第一次用60÷4＝15升，剩45升；第二次用45÷3＝15升，最后45－15＝30升，与题意一致。

## 五、两道有变化的训练

两题均为单选，答错可重选。每题有“展开图解”内容，完整图解在作答后可查看并可回看；短正确反馈不替代解析。

### 训练一：近迁移，第二次会取走不止一个原来的等份

**题目：** 一桶水，第一次用去原来总量的1/5，第二次用去第一次剩下水量的1/2，最后剩28升。原来有多少升水？

**变化与重新判断：** 分数及最后水量改变。第二次的单位“1”仍是第一次后剩量，但取它的1/2时，应把剩下4格分成两组，每组2格；不能沿用主例“第二次拿走一格”的动作。

| 选项 | 判断及针对性反馈 |
|---|---|
| A. 56升 | 错。28×2＝56求出的是第二次之前的水量，也就是第一次后剩下的4份；还要还原原来的5份 |
| B. 35升 | 错。28÷(4/5)把28升误当成第一次后的水量，漏掉了第二次用水；先由最后的28升还原第一次后的水量 |
| **C. 70升** | **对。最后2份共28升，原来5份共70升** |
| D. 140升 | 错。28×5把最后剩水当成原来1份；图上第二次留下的是4格的一半，也就是2格 |

**可展开图解：**

1. A条“原来总量：单位1”分5个等宽格，每格为原量的1/5。第一次用去1格，余4格。
2. B条“第一次后剩量：新的单位1”保留4格，与A条同尺度。B条每格为第一次后剩量的1/4；要表示它的1/2，应将4格分成两组，**每组2格**。第二次用去一组，留下另一组。
3. 给留下的2格标共28升，所以一格28÷2＝14升；原来5格为14×5＝70升。

**独立算式核验：**

\[
28\div\left[\left(1-\frac15\right)\left(1-\frac12\right)\right]
=28\div\frac25=70\text{（升）}.
\]

**回代：** 原来70升，第一次用14升、剩56升，第二次用56×1/2＝28升，最后剩28升。最后占原量2/5，比例为正；存在且仅有一个正解，各阶段70＞56＞28＞0。

### 训练二：改变第二次的比较基准

**题目：** 一桶水，第一次用去原来总量的1/4，第二次用去**原来总量的1/3**，最后剩30升。原来有多少升水？

**变化与重新判断：** 数字沿用主例，第二次的单位“1”改为原来总量。两次用水的分数现在有相同基准，必须重新读题，不能沿用“最后剩一半”的结论。

| 选项 | 判断及针对性反馈 |
|---|---|
| A. 60升 | 错。这是把第二次仍看成“第一次后剩量的1/3”的结果；本题加粗处写的是“原来总量的1/3” |
| **B. 72升** | **对。两次都按原量计算，最后剩原量的5/12** |
| C. 40升 | 错。30÷(3/4)只还原了第一次用水，忽略了第二次用去原量的1/3；先算两次之后还剩几格 |
| D. 360/7升（即51又3/7升） | 错。1/4＋1/3＝7/12是两次合计用去的比例，30升对应的是留下的5/12 |

**可展开图解：**

1. 两次单位“1”都为原量，只需一条明确标“原来总量：两次共同的单位1”的等份条。
2. 为使1/4与1/3都能用完整格子表示，将全条平均分成12格：12既能按4组均分，又能按3组均分。每格是原量的1/12；1/4对应3格，1/3对应4格。**12格来自统一比较基准后的等分需要，不是凭空指定。**
3. 第一次标记用去3格，第二次在余下部分再标记用去4格，两组不重叠，最后留下12－3－4＝5格。第二次虽从桶内剩水中取走水，其规定数量仍是原量的4/12，不能按当时剩下9格的1/3计算。
4. 剩下5格共30升，每格30÷5＝6升；原来12格为6×12＝72升。

**独立算式核验：**

\[
30\div\left(1-\frac14-\frac13\right)
=30\div\frac5{12}=72\text{（升）}.
\]

**回代：** 原来72升，第一次用18升、剩54升；第二次用原量的1/3，即24升；最后54－24＝30升。第二次用24升不超过当时54升，条件可实现。剩余比例5/12为正，存在且仅有一个正解，各阶段72＞54＞30＞0。

**与主例对照时保留的关键判断：** 主例的第二次1/3看B条；本题的第二次1/3看原来整条。同样写1/3，必须先确认“谁的1/3”。
